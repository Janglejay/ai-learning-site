Agent 重点路线

K4 工作流、有界 Agent 与记忆 是入口。A2 Agent 与任务环境 提供智能体与环境的基础，K7–K12 展开专项，L5/L6 接到自建平台。已有后端经验可从第一站开始，根据知识点的先修回补。

贯穿项目：考证开源项目的版本能力、给出证据链接。用同一批题比较无工具、固定工作流、手写 Agent 和 DSH。

入门练习见 两周理论与动手练习，完整专题对照见 Agent 知识分支与 DSH 覆盖边界。

1. 最小 Agent

已有后端经验可以从这一站开做。补齐任务环境、一次模型请求和工具契约。手写两个只读工具、一个循环、一个预算终点。交付成功与失败轨迹。

知识点：A2 Agent 与任务环境 · A3 人机协作与任务边界 · B1 Python、NumPy 与复现 · H7 解码、推理模型与测试时计算 · K1 提示、结构化输出与契约 · K3 工具调用与接入协议 · K4 工作流、有界 Agent 与记忆

  • Agents Course
  • Building effective agents
  • ReAct 原论文

2. 公开资料助手

用同一批版本考证题接入索引、引用、规划与记忆。保留资料冲突、证据不足和故障用例。

知识点：C6 自动规划与调度 · J1 信息检索与排名评测 · K2 RAG、引用与知识治理 · K8 Agent 推理与规划实验 · K9 上下文与长期记忆策略

  • CS276 Information Retrieval and Web Search
  • Introduction to Information Retrieval
  • Retrieval-Augmented Generation 原论文
  • LLM Agent 规划综述

3. 固定基线和评测

比较单次调用、固定工作流和手写 Agent。先定正确率、引用支持、费用与时延，再让 DSH 用同一套题。防护和人工接管同时验收。

知识点：E5 泛化理论与模型评估 · D5 因果推断与实验思维 · K5 应用评估、轨迹与防护 · K12 Agent 评测与可重复对照实验 · M1 责任、隐私与公平 · M2 治理与风险验证

  • Demystifying evals for AI agents
  • Evaluation and Benchmarking of LLM Agents
  • OWASP Agentic Applications 风险目录

4. 读 DSH 并跑对照

顺着事件追踪一次工具调用，把手写循环映射到 DSH。自己写一个小工具，固定依赖版本，用同题对照。

知识点：K7 Harness 运行时与插件 · K3 工具调用与接入协议 · K12 Agent 评测与可重复对照实验

  • DeepSeek Harness 架构
  • DeepSeek Harness SDK 协议

5. 搭自己的平台

完成任务列表、事件流、停止、重启核对、审批与运行成本。用模拟服务证明超时和未知结果有明确处理。

知识点：L4 数据工程与可复现实验包 · L5 Agent 持久执行与控制面 · L3 MLOps、版本与发布 · L6 Agent 生产可靠性与经济性 · M4 毕业项目：公开资料助手

  • DeepSeek Harness SDK 协议
  • DSH Super-agent 原型
  • The Site Reliability Workbook：Implementing SLOs
  • OpenTelemetry GenAI 语义约定

6. 按方向深入

先迁移到代码或模拟工单，再按兴趣做多 Agent、模型后训练、多智能体 RL、具身实验或本地推理部署。

知识点：K6 AI 辅助研发与验证 · K10 LLM 多 Agent 编排与互操作 · K11 浏览器、桌面与领域 Agent · H9 Agent 模型后训练与适应 · G5 多智能体强化学习 · I5 具身学习与仿真迁移 · L2 推理服务与模型压缩
